# .whizbang/

Whizbang writes files here in two categories.

## Committed — the files directly in this folder

- `pinned-type-ledger.json` — the pinned-type rename lockfile. **Commit it.** It records
  rename history (former-name aliases) that cannot be regenerated from source, so old
  serialized events keep deserializing after a type is renamed.

## Ignored — everything under `cache/`

- `message-registry.json` (when `WhizbangEmitMessageRegistry=true`) and generated `.cs` files (when
  `EmitCompilerGeneratedFiles=true`), rebuilt from source on every build.

Add `**/.whizbang/cache/` to your `.gitignore`. Commit everything else in `.whizbang/`
(including this README).

_Generated by the Whizbang build. Set `WhizbangEmitFolderReadmes=false` to stop._

# Every build diagnostic ID in this repository: the shipped generators and analyzers, the repository-internal
# analyzers (src/Whizbang.TestAnalyzers, tools/Whizbang.RepoAnalyzers) and the MSBuild checks in
# Directory.Build.targets. One ID space, one form: WHIZ and three digits, each ID unique.
#
# A new diagnostic takes the lowest free WHIZ number in its block here, and its row is added in the same change.
# .github/scripts/Test-DiagnosticIds.ps1 (run by "Test · Pipeline scripts") fails when an ID is defined but not
# listed, listed but not defined, listed under a project that does not define it, or outside the WHIZ form.
#
# Columns: id | status | owner | meaning
#   status  active   defined and reported today
#           retired  never to be reused; must also be in DiagnosticDescriptors.RETIRED_IDS
#           legacy   shipped in a package before the single WHIZ form; consumers may suppress it by name, so it
#                    keeps its ID. A frozen set that only shrinks; a new ID is never legacy.
#   owner   the project under src/ or tools/ that defines it (comma-separated when two do, by design), or the
#           root MSBuild file
#   meaning one line; the descriptor title for an analyzer or generator diagnostic
#
# Blocks: WHIZ600-699 is the repository-internal block (MSBuild checks, test analyzers, repository analyzers); every
# other number belongs to the shipped packages. The repository-internal checks were WHZ0001 to WHZ0005 until they
# were renumbered into WHIZ600-604 (CHANGELOG.md).

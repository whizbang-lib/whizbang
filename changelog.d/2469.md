- **The shared perspective runner logic is library code in Whizbang.Core, no longer generated into each assembly
  (#2469).** Every generated perspective runner now derives from
  `Whizbang.Core.Perspectives.PerspectiveRunnerBase<TPerspective, TModel>`, a public abstract class shipped in
  Whizbang.Core, instead of an internal copy (`PerspectiveRunnerBase.g.cs`) the generator emitted into every assembly
  with a perspective. One copy serves every consumer, and the runner logic (reads, folds, writes, rewinds, rebuilds,
  snapshots and collectives) is now under the library's test coverage and analysis. Runner behavior is unchanged,
  AOT-safe and reflection-free; a runner still emits only what its perspective varies. The class is public only so the
  generated runners can derive from it; it is not an extension point for hand-written runners. Nothing to change: the
  generator and Whizbang.Core ship together, and a rebuild regenerates the runners against the new base.

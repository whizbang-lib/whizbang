- **A cursor naming an older copy of a superseded key no longer holds that copy forever (#2433).** When the cursor's
  perspective has applied the key's newest copy and has no work pending up to it, the superseding reaper moves the
  cursor on (to the newest copy, or to the event before a restored older copy stored above the newest) and reaps the
  older copy, as it already hands the key's digest slot on. A cursor flagged for a rewind is left to the rewind.
  Cursors already parked this way are released by the next maintenance cycle. Migration 532. Nothing to change.

- **The build reports the two Sonar rules the merge queue gates library code on (#2515).** Contributor-facing only:
  cognitive complexity above 15 (S3776) and more than 7 parameters (S107) in `src/` are now build errors, locally, in
  the editor and in pull request CI, at the thresholds SonarCloud uses for this project, instead of first surfacing as
  a failed quality gate in the merge queue. SonarAnalyzer.CSharp ships both rules turned off, which is why a clean
  build said nothing before. `src/` had no violation when the rules were turned on, so there is no baseline; tests,
  samples, benchmarks and tools stay out of scope because the quality gate does not check them with these rules. A
  reviewed exception keeps using `[SuppressMessage]` with its reason. Nothing to change for consumers of the packages.

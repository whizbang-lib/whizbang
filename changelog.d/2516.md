- **A strong id can accept a list of UUID versions, between UUIDv7 only and any version (#2516).**
  `[WhizbangId(Versions = UuidVersions.V7 | UuidVersions.V5)]` generates an id whose `From`, `Parse`, explicit
  cast, transport JSON reader and GraphQL scalar accept exactly the listed versions and throw an
  `ArgumentException` naming them otherwise (`ConnectorId requires UUIDv5 or UUIDv7 but received version 4`).
  `Guid.Empty` is refused, `New()` still mints UUIDv7, and the constructor and `Value` initializer stay unchecked.
  An id minted with `New()` and derived with `NameBasedGuid.V5` can now stay strict instead of opening up with
  `AcceptAnyVersion = true`, which remains the shorthand for any non-empty Guid. `Versions` defaults to
  `UuidVersions.V7`, so existing ids generate the same code. Declarations of one id (struct, property, parameter)
  that list different versions resolve to the versions they have in common, reported by the new warning WHIZ037;
  WHIZ029 now names the versions an ignored `AcceptAnyVersion` opt-in resolves to. `AcceptAnyVersion = true`
  written with `Versions` is the new error WHIZ038, and an id that accepts no version is the new error WHIZ039.

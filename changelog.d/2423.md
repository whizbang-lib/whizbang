---
category: Changed
subsection: Storage
---
- **A read of a perspective model's stream id reads the row's id, not the document (#2423).** A `Select`, a sort, a
  `GroupBy` key or selector, or a `Min` or `Max` over a model's `[StreamId]` property, in the row form
  (`r.Data.OrderId`) or after `Select(r => r.Data)`, now reads the row's `id` column. A query whose other columns are
  `[PhysicalField]` columns no longer reads, or de-TOASTs, each row's document just for the id, and a sort on the stream
  id is served by the primary key. The runner writes a row at its stream id and seeds the model's `[StreamId]` from it,
  so the value is the same for a model that keeps that contract. Filters are unchanged: they keep their document test
  beside the primary key (#2303). **Upgrade:** a row whose document was written with a stream id other than its row id
  now reads back its row id from such a query; nothing to change for a model that keeps the contract, and a second
  physical column duplicating the primary key is no longer needed.

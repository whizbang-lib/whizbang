- **A perspective cursor no longer stays behind an event its own run applied (#2432).** The batched completion path
  could store a run's cursor in an earlier flush than the retirement of that run's work rows. The cursor was then held
  before the run's own still-pending rows, and the later flush that retired them carried no cursor, so a stream that
  received no further event kept a cursor naming an event its perspective had already passed (and the superseding
  reaper kept that event). The rows of the events a completion reports applied no longer hold its cursor; a pending
  event the run did not report still does. Migration 531. Nothing to change.

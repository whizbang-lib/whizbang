- **Stream cleanup no longer reads the whole outbox for each stream it evicts (#2538).** After perspective work
  completes, the streams left with nothing to do are removed from the stream ledger, and each is first checked for
  pending outbox work. No outbox index answered that check, so every candidate stream read the whole outbox: with
  12,500 pending outbox rows, a batch of 1,000 streams read about 381,000 blocks. The check now asks for the outbox rows
  the claim can still take, which an existing index answers, and the same batch reads about 5,000 to 6,000 blocks. No
  index is added, so writing to the outbox costs the same. The streams evicted are unchanged for every row the
  framework writes. Nothing to change.

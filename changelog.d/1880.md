- **CI's self-hosted runner pool now copes with machines that come and go (#1880).** A pool machine takes a job only
  while a recent self-check shows it can do that job (PowerShell 7, free disk, upload speed for the build, a working
  Docker for the container suites), so a machine that is online but unfit is skipped without anyone changing its
  labels. A run whose pool job no machine will start is canceled once nothing else is running, and a run that
  failed only because a pool machine was lost has its failed jobs re-run on GitHub-hosted runners, where they must
  still pass. A job re-run without the picker ("Re-run failed jobs") now runs on GitHub-hosted runners instead of
  the labels picked for the first attempt. Merge-queue runs are not re-run: requeue the pull request. Nothing to
  change for consumers of the packages.

- **An EF Core host that registers no separate connection checks the perspective registry on every start (#2578).**
  A context configured over a connection of its own gave the initializer no way to open a second one, so its stored
  perspective registry was reconciled only inside the schema pass, and a start that skipped the pass (every hash clean,
  or a restored database) kept whatever registry it found. The check now runs on the context's own connection when no
  separate one can be opened, opening it only if it was closed and closing it again afterwards. Nothing to change.

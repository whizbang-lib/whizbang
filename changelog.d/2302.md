- **A filter on a perspective model's `Guid` `[StreamId]` property also reads the row by its primary key (#2302).**
  `Where(r => r.Data.OrderId == id)` and `ids.Contains(...)` now add `id = @id` (or `id = ANY (...)`) beside the
  document test, so a point read by id uses the primary key instead of a document search. A filter written after
  `Select(r => r.Data)`, past any `OrderBy`/`ThenBy`, as GraphQL filtering layers write it, is moved onto the row,
  so it reaches the primary key and `[PhysicalField]` columns too. The document test is kept, so no query returns
  a row it did not before; a row whose `[StreamId]` property was set to something other than its stream id is no
  longer found by that property. String and strongly-typed keys, and tests under `OR` or `NOT`, are unchanged.
  Nothing to configure: the generator registers each model's stream id.

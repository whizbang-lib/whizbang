- **The data-only role end-to-end test no longer fails because a build server is busy (#2508).** Each of its phases
  (a start, a stop, the maintenance steps, a publish and apply) had a wall-clock bound of its own, 60 s, and a second
  start whose Converge stage ran longer than that on a loaded server failed the test with nothing wrong. Each phase now
  waits on its own completion signal for as long as it takes, and one deadline for the whole test, just inside the
  test's own timeout, is the hang detector: a test that runs past it fails naming the phase and startup stage it stopped
  in, as before. The library itself is unchanged.

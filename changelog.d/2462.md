- **The claim-cost check of the partition assignment no longer fails when other work shares the database server
  (#2462).** It compared shared-buffer counts, which include catalog reloads and index metapage rereads another
  session can cause, and the dead rows an earlier rolled-back claim left behind. It now compares the rows each claim
  read, counted by the backend inside the claim's own transaction on tables vacuumed before every measurement, which
  are the same whatever else runs on the server. Nothing to change.

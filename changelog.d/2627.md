- **Vector bodies stored before packing began are packed too, and an operator can unpack every stored body before a
  planned downgrade (#2627).** Once the packing gate is open, the `stored-vector-conversion` maintenance step packs
  the vector events stored earlier, in bounded, resumable batches per event type, each body once, and only when the
  packed body stores smaller after compression: a vector rounded to a few decimals stays JSON numbers. Before rolling back
  to a build that cannot read packed vectors (or one whose `[StoredAsJsonArray]` opt-outs differ), run
  `SELECT wh_request_vector_unpack('<who>', '<why>')`: packing stops at once and stays held, the step writes every
  packed vector in the event store and the archive back as the JSON numbers it held (byte-equal), and once nothing is
  packed it clears `wh_packed_vector_paths` and the packed-vectors journal entry, so the older build starts. Run
  `SELECT wh_resume_vector_packing('<who>', '<why>')` to pack again. Nothing to change otherwise.

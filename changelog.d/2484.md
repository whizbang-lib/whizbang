- **Two builds of the same commit now produce byte-identical packages (#2484).** Anyone with a release's commit and the
  SDK in `global.json` can rebuild its packages and get the published bytes. Package entries carry one fixed timestamp,
  generators sort names in ordinal order instead of the build machine's culture order, the message registry maps the
  source paths it embeds through the build's path map (a CI build reads `/_/src/...`), and each generator embeds its
  symbols, so its merged assembly records no temporary path; the one assembly the tests load is the one its package
  ships. Every release branch and a weekly run on develop build the commit twice and fail on any difference. With no
  path map, a local build's registry keeps full paths for the editor. Nothing to change.

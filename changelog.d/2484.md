subsection: Observability & tooling
---
- **Two builds of the same commit now produce byte-identical packages (#2484).** Anyone with a release's commit and
  the SDK in `global.json` can rebuild its packages and get the published bytes. Package entries carry one fixed
  timestamp, generators sort names in ordinal order instead of the build machine's culture order, the message registry
  maps the source paths it embeds through the build's path map (a CI build reads `/_/src/...`), and the generator
  packages ship a merge without the temporary symbol path ILRepack embeds. Every release branch and a weekly run on
  develop build the commit twice and fail on any difference. A local build is unchanged: with no path map the registry
  keeps full paths for the editor. Nothing to change.

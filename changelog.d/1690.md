category: Changed
subsection: Observability & tooling
---
- **The receptor generator finds the concrete subtypes of every polymorphic message type in one pass (#1690).** A
  receptor declared on an interface or base type is widened to the concrete messages that implement it, and every
  non-sealed message class counts as polymorphic, so a large consumer asks for hundreds of them. Each was found by its
  own walk of every type in the compilation and its references, which made the generator's cost grow with the number
  of message types times the number of types. One walk now answers them all, with the same subtypes in the same
  order. Nothing to change; a large consumer builds faster.

- **Stored bodies leave the database as JSON numbers (#2626).** A packed vector (#2625) never leaves packed: the
  redelivery selection (which an integrity repair sends to a peer and the audit rebuild re-records) and the trace
  store's payload read the body through `wh_event_body_wire_form`, which writes each packed vector back as the numbers
  it was packed from. A test derives every read of a stored body by machine and fails an export that skips the wire
  form. Nothing to change.

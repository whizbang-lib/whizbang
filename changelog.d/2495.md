- **CI fails on a `<docs>` tag whose docs-site page or anchor does not exist (#2495).** Contributor-facing only: the
  "Test · Pipeline scripts" job clones the docs site's `develop` branch and checks every `<docs>` tag under `src/`,
  `tests/`, `samples/` and `tools/` against it, resolving pages and heading anchors the way the site does. The 308
  targets that already dangled are listed in `.github/scripts/docs-tag-target-baseline.txt`; a new dangling target
  fails the job, and so does a listed target that has since been fixed, so the list only shrinks. A docs repository
  that cannot be fetched fails the job rather than passing it. Nothing to change for consumers of the packages.

- **A reap-driven snapshot is now a rewind floor for a late event below the cursor (#2296).** Before a maintenance cycle
  reaps a stream's consumed ephemeral bodies, the reap-driven pass bootstraps a snapshot for each (stream, perspective)
  it would otherwise hold back. It used to snapshot the row at the cursor, the stream's tip, which is a floor only for a
  late event placed after it: once the bodies below were reaped, a late event below the tip found no floor and an
  ephemeral perspective dropped it. The pass now names the reap boundary (the last body it is about to reap) and folds
  the model as of that boundary from the snapshot below it and the bodies still stored, so a late event below the
  cursor but above the boundary rewinds from it. One snapshot slot per stream as before; the coverage gate is unchanged.
  A model with collectives is still snapshotted at the cursor. A boundary that cannot be folded from what is stored is
  reported as `SnapshotBootstrapOutcome.Refused` and its bodies wait. Nothing to change.

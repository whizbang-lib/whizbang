category: Added
subsection: Storage
---
- **Event readers accept vectors stored as packed binary32 (#2624).** Every `float[]` and `IReadOnlyList<float>`
  property of an event now reads either a JSON array of numbers or one base64 string of the big-endian binary32 bits
  of its elements, bit-exact (`-0`, subnormals and NaN payloads included). Writing is unchanged: this release writes
  only arrays, so it can read the smaller stored form a later release will write once every live instance can read
  it. Mark a property `[StoredAsJsonArray]` to keep it stored as numbers; `double[]` is never packed. Nothing to change.

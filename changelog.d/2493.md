category: Changed
subsection: Work coordination, perspectives & sagas
---
- **An event listed only by a custom perspective interface is a build error even when that interface declares its own
  `Apply` (#1943).** A custom interface that extends `IPerspectiveBase` and declares, for example,
  `TModel Apply(TModel, TEvent)` silenced WHIZ117, yet the generated runner calls `Apply` only through
  `IPerspectiveFor`, `IPerspectiveWithActionsFor` and `IGlobalPerspectiveFor`, so that `Apply` never ran and the
  event was silently not applied (a class implementing only the custom interface got no runner at all). WHIZ117 now
  reports such an event at the perspective. **Upgrade:** list the event under one of the three built-in interfaces as
  well (or instead); the existing method satisfies `IPerspectiveFor` when it returns the model and
  `IPerspectiveWithActionsFor` when it returns `ApplyResult<TModel>`. Support for custom perspective interfaces with
  their own `Apply` contract is still planned.

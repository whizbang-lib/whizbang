- **A rewind flagged from an event its perspective does not read now runs, and no longer holds startup or leases its
  row forever (#2601).** The origin-position fill could flag a cursor to rewind from an event of a type its perspective
  does not read (the stream's first event, under the fill's first, stream-wide rule). The drain forms a pair, and so
  runs a flagged rewind, only for an event the perspective applies, so that rewind never ran: its queued row was leased
  on every pass with `failures` 0 and no error, the dead-letter bound (which reads failures) never applied, and a worker
  in Blocking startup mode waited the full cap on every start. Five changes. A rewind and its floor now count only
  events of a type the perspective's association rows name: the trigger only when the perspective reads it, and a
  perspective with no association rows reads nothing, so the fill neither rewinds it nor, when only events a
  perspective does not read moved, rewinds that one (migration 602, `wh_rewind_reap_floor`; a one-off repair,
  `_wh_repair_rewinds_from_unread_events`, moves an already flagged trigger to the first event its perspective reads,
  or clears the flag when there is none, and deletes the queued rows nothing would apply). The worker runs the flagged
  rewind from the stored trigger when a flagged cursor's queued rows hold no event it applies, and completes the rows
  (EventId 93). A new maintenance step removes the cursors, queued rows and snapshots of a perspective this service does
  not register and no service's association rows name (`Whizbang:Workers:Perspective:UnregisteredPerspectiveCleanup`,
  on by default; counted on `whizbang.perspective.unregistered_cursors_removed`). A queued row leased
  `Whizbang:Workers:Perspective:LeasedWithoutFailureWarningAttempts` times (default 25) with no failure is warned about
  once (EventId 94) and counted on `whizbang.perspective.rows_leased_without_failure`, and the startup cap's Warning
  names how often the queued row of each cursor still rewinding was leased. Nothing to change.

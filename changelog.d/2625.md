- **Vector event bodies are stored packed once every live instance can read them (#2625).** The stored body of an
  event (not the outbox, inbox or wire) holds each vector property as base64 of its binary32 bits instead of JSON
  numbers, lossless, written in SQL by both emit chains and the direct append. Packing waits for the fleet: each
  heartbeat now records `stored_form_level` 2, and the `vector-packing-gate` maintenance step opens packing only once
  every live instance records it. Opening journals the conversion (`stored-form:wh_event_body:packed-vectors`) with the
  library version, so an older library stands down at startup instead of meeting a body it cannot read; an application
  rolled back on the same library is not affected. The generator registers each event type's vector paths, and a
  vector inside a collection element, behind a polymorphic member or in a self-referencing type stays a JSON array and
  is reported as WHIZ064 (Info). A `List<float>` or `ReadOnlyMemory<float>` on an event counts as a vector when it is
  marked `[VectorField]` (an unmarked one is left alone); on an event, `[VectorField]` needs no pgvector package.
  Nothing to change; mark a property `[StoredAsJsonArray]` to keep it as numbers.

- **The generator registers each event type's vector paths (#2625).** For every event type, the paths of its
  `float[]` and `IReadOnlyList<float>` properties (the JSON names from the payload's root) are registered in
  `StoredVectorPaths` at load, for the stored-body packing to read. A vector inside a collection element, behind a
  polymorphic member or in a self-referencing type has no fixed path, stays a JSON array, and is reported as WHIZ064
  (Info). Nothing to change.

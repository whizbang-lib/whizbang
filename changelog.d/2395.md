- **A worker stopped during startup no longer keeps its change-notification handler (#2395).** On .NET 10 and later
  the host starts a worker's main loop on the thread pool, so a stop could arrive while the perspective worker was
  still attaching its handler for database change notifications. The handler then stayed attached, kept waking the
  stopped worker and kept it in memory. Stopping now always detaches it. **Upgrade:** nothing to change.

- **Every schedule occurrence is published: its id is now a UUIDv7 (#2599).** An occurrence's id is its outbox message
  id, and the outbox refuses one that is not a UUIDv7. A scheduled fire's id was an md5 hash, a v7 about one time in
  sixteen, so most fires were refused, and `TriggerNowAsync` minted a v4, so every manual trigger was. A scheduled
  fire's id is now a UUIDv7 stamped with the occurrence's scheduled fire time, the rest hashed from the schedule and
  occurrence number, so competing claimers still agree on it; a manual trigger takes a fresh UUIDv7 on the database
  clock. Ids already stored are not rewritten.

- **The EF Core test fixtures tear down once (#1954).** Contributor-facing only: every EF Core Postgres test fixture
  creates its scratch database through `PerTestDatabaseFactory`, and a fixture with an `[After(Test)]` hook is no longer
  also disposable, so its teardown runs exactly once. A guard test fails a fixture that is both. Nothing to change for
  consumers of the library.

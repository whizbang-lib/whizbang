subsection: Startup
---
- **The Dapper driver reports the Migrate startup stage and a progress line for every migration step, as the EF Core
  driver does (#2579).** A Dapper start that migrates now enters Migrate with how many steps the pass owes, logs
  `Migration X of Y - Started`, then `Succeeded`, `Skipped` or `Failed`, for each migration file and perspective table,
  and ends with `Migration complete` or `Migration stopped at`. Both drivers write these lines through one shared
  reporter, so they read the same on either. Nothing to change.

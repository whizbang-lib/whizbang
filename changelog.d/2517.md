- **A strict strong id can accept a frozen set of grandfathered values (#2517).** Every generated `[WhizbangId]`
  type declares `static partial void IsGrandfathered(Guid value, ref bool grandfathered)`. An id type that
  implements it (typically a `FrozenSet<Guid>` lookup) lets `From`, `Parse`, the explicit cast, the transport JSON
  reader and the GraphQL scalar accept the values it names even when their version breaks the id's rule (UUIDv7, or
  its `Versions` list), while every other value is still refused. Seed data with hand-typed ids and well-known system
  identities can stay as they are without opening the whole type with `AcceptAnyVersion = true`. `Guid.Empty` is
  never grandfathered and `New()` still mints UUIDv7. An id that does not implement the hook behaves as before: the
  compiler removes the call.

- **A database one schema pass has built reads as current on the next start (#2194).** The stored-form conversions
  ran before the pass created the perspective tables, so on a new database they settled nothing, and the second start
  ran a pass it did not need; the database read as current only from its third start. The instance that completes a
  pass now settles the conversions on the tables it built, before it gives up the migrator role, so the next start's
  Assess reads Current and takes no schema lock. Nothing to change.

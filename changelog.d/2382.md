- **The EF Core registration block is emitted from templates (#2382).** The code the EF Core generator writes for each
  DbContext (promoted and indexed fields, the hydrators, Split document projections, stream ids, the data coalescer,
  multi-model lens queries and the managed-object manifest) now comes from one snippet per registration kind, as the
  perspective and infrastructure registrations already did, instead of string concatenation. The generated code is the
  same apart from four comments, which no longer contain a dash character. Nothing to change.

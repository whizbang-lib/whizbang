subsection: Startup

- **A restart no longer waits on unrelated transactions when its stored-form rewrite converts nothing (#2419).** The
  rewrite phase records a ledger row for a table it has not yet seen settled, such as one created on the previous
  start. That write alone made the phase wait, after its commit, for every older transaction that had written anywhere
  on the database server, other databases included, for up to the schema command timeout, logging only at Information.
  On a busy shared server a restart stalled in its schema pass. The phase now waits only when a rewrite changed a
  table's rows, and a stored-form migration that converted rows now marks its table like the other rewrites, so its
  table is also analyzed afterward. Nothing to change.

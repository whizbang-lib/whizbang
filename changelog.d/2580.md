- **The claim's re-offer walk can start at a fixed point for a measurement (#2580).** Each walk still starts at a
  stream drawn at random, so a lane larger than the batch is not re-offered from the same streams on every poll. A
  session that sets `whizbang.claim_walk_seed` to a stream id starts every walk there instead, so two measurements of
  one workload read the same pages. Nothing in the framework sets it, and a pooled connection's reset clears it.

---
category: Changed
subsection: Messaging & delivery
---
- **A `[StreamId]` reached through an interface resolves, and an ambiguous one is a build error (#1908).** Stream-id
  resolution is keyed by a message's concrete type and the property it actually exposes, through one lookup on its
  type instead of a chain of type checks whose order decided the answer. A type with no `[StreamId]` of its own now
  takes one declared on an interface it implements, read through the property that implements it; before, an
  interface's `[StreamId]` was ignored and the message had no stream id. A type that gets `[StreamId]` from two or more
  sources naming different properties (two interfaces, or an interface and a base class) and declares none of its own
  is reported by the new error WHIZ036 and gets no stream id. **Upgrade:** for a type WHIZ036 reports, declare
  `[StreamId]` on the property of that type that is its stream id.

- **Filling a received event's missing origin position rewinds only the perspectives whose own replay order changed,
  from the first version that changed (#2571).** The fill used to decide once per stream and then rewind every
  perspective of the stream from its first event, deleting all of its snapshots. Because each perspective replays
  only the event types it handles, that rewound perspectives whose order had not changed (the main cost of the fill:
  their replays read the whole stream again) and missed a perspective whose own order had changed while the stream's
  had not, leaving its row folded in the old order. Each perspective is now compared over its own events (all of the
  origin's events when it has no association rows), rewound from the first changed version, and keeps its snapshots
  below that version; a rewind already due from a lower version keeps its trigger, and the rewind count names only
  cursors that were not already flagged. No action is needed.

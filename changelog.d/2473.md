- **The stream lifecycle cost scenario no longer fails when other work shares the database server (#2473).** Its
  vacuum had to mark every page it measured all-visible, and a snapshot held elsewhere (an autovacuum worker analyzing
  a catalog of the test's database, or a backend whose snapshot reached back to a transaction open in another database)
  left a page unmarked. The vacuum now runs once nothing on the server can still see an older version of the rows,
  a condition that stays true once it holds. Nothing to change.

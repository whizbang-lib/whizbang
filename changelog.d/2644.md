- **A settled rewind flag no longer leaves its trigger behind (#2644).** When a perspective cursor's RewindRequired
  flag was settled (its work completed, its last pending row retired, or the stale-flag sweep), only the status bit was
  cleared; the cursor kept the flag's trigger event and its flagged times. The next late event on that stream merged
  with the dead trigger, so its rewind replayed from an event the cursor had already settled, the tip snapshot taken
  without the late event was not dropped, and the first-flagged time dated from the old flag. A cursor without the flag
  now holds no trigger and no flag times, whichever path settles it (migration 664, a trigger on
  `wh_perspective_cursors` that calls no function on an ordinary write), and the cursors an older build left with a
  dead trigger are cleared once on startup. **Upgrade:** nothing to change; the migration runs on startup.

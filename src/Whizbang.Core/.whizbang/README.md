# .whizbang/ — committed Whizbang files

This folder holds Whizbang **source-of-truth** files that MUST be committed to git.

- `pinned-type-ledger.json` — the pinned-type rename lockfile. It records the history of
  type renames (former names / aliases) so old serialized events still deserialize. This
  history cannot be reconstructed from source, so it must live in version control.

**Commit this folder. Do NOT git-ignore it.** The regenerable message catalog lives
separately in `.whizbang-generated/`.

_This file is generated by the Whizbang build. Set `WhizbangEmitFolderReadmes=false` to stop._
